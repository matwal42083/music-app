# Music App

A browser-based music player that streams real digital audio. This freeCodeCamp learning project is a fun step toward a longer-term goal: building a Spotify-inspired music app.

## About the Project

This app was built as part of freeCodeCamp's [Learn Basic String and Array Methods by Building a Music Player](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/learn-basic-string-and-array-methods-by-building-a-music-player/step-1) curriculum. It uses JavaScript to manage a playlist and control playback of hosted MP3 tracks.

This is a learning project and starting point for exploring how a Spotify-inspired app could work; it is not affiliated with Spotify.

## Features

- Play and pause songs
- Skip to the next or previous track
- Shuffle the playlist
- View track titles, artists, durations, and album art
- Remove tracks from the playlist and restore the original playlist

## Run the App

Open `index.html` in a web browser. An internet connection is needed to load the hosted music, album art, and Google Fonts.

## Built With

- HTML
- CSS
- JavaScript
- HTML Audio API

## Project Files

- `index.html` — music player and playlist structure
- `styles.css` — player layout and styling
- `script.js` — playlist data and playback controls
